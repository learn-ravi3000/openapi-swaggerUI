#2.0.0 enhancments
1) Config-driven service catalog - Externalize the list of API doc endpoints (YAML/JSON). Expose /swagger-config.json that Swagger UI reads so you don’t rebuild to add a service.
2) Heartbeat test - Cache fetched specs (short TTL), show per-service health badges, and fail gracefully if a spec is down.

## Run and validate
Run mvn spring-boot:run and 
verify http://localhost:8082//swagger-config.json and 
http://localhost:8082//aggregated/health reflect your real service catalog.

Populate services.yml (or an external catalog file) with the target environment endpoints and confirm Swagger UI picks them up automatically.
